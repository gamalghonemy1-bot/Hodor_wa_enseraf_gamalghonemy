# حضور الطلاب (QR) — Flutter

تطبيق أندرويد لتسجيل حضور وغياب الطلاب بمسح QR. قاعدة البيانات SQLite محلية على الهاتف، بلا أي خدمة مدفوعة أو خادم.

## الوظائف
- إدارة الفصول والطلاب والحصص (إضافة/تعديل/حذف).
- لكل طالب رمز QR فريد (يُعرض ويُشارك كصورة، وبطاقات الفصل تُطبع PDF).
- مسح QR لتسجيل الحضور؛ منع التكرار (قيد UNIQUE في القاعدة + فحص قبل الإدراج)، وقبول المسح فقط أثناء وقت الحصة ولطلاب نفس الفصل.
- الغياب التلقائي: بعد نهاية وقت الحصة يُسجَّل غياب كل من لم يحضر (يعمل عند فتح التطبيق/عودته للواجهة، ودورياً كل 30 ثانية أثناء فتحه، وقبل أي تقرير).
- تقرير شهري PDF عربي (RTL) لكل فصل.
- نسخ احتياطي (حفظ في ملف / مشاركة) واستعادة مع التحقق من الملف.

## البناء عبر GitHub Actions (مجاني)
1. ارفع محتويات هذا المجلد إلى مستودع GitHub (الفرع main).
2. تبويب Actions ← Build APK ← يعمل تلقائياً عند الدفع أو يدوياً (Run workflow).
3. بعد النجاح: افتح التشغيل ← Artifacts ← `attendance-qr-apk` ← حمّل `app-release.apk`.
4. لإصدار رسمي: `git tag v1.0.0 && git push --tags` يرفق الـ APK بصفحة Releases.

## البناء محلياً
```
bash tools/prepare_android.sh   # يولّد android/ ويضبط الصلاحيات
flutter pub get
flutter build apk --release
```
ملاحظة: الـ APK موقّع بمفتاح debug (كافٍ للتثبيت المباشر). للنشر على Google Play أنشئ keystore خاصاً بك.
